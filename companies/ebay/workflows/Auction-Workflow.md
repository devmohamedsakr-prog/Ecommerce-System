# eBay Auction Workflow

## Create Auction
1. Seller sets: item, starting bid, reserve, duration
2. Item listed immediately
3. Search indexed within seconds

## Bidding Process
1. Bidder enters max bid
2. Proxy bidding: automatic increments up to max
3. Outbid notification to previous bidder
4. Real-time bid updates

## Auction End
1. Countdown timer reaches zero
2. Auto-close auction
3. Winner notified
4. Payment email sent
5. 24-48 hour payment deadline

## Post-Sale
1. Buyer pays
2. Seller ships
3. Tracking provided
4. Delivery
5. Feedback exchanged
