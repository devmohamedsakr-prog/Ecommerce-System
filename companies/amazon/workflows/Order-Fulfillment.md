# Amazon: Order Fulfillment Workflow

## Order Placement
1. Customer adds to cart
2. Checkout: Payment, address
3. Delivery option selected (Standard, 2-day, 1-day, Same-day)
4. Order placed
5. Confirmation email sent

## Fulfillment Center Routing
1. System determines nearest FC with stock
2. Order routed to fulfillment center
3. Time: <30 minutes from order placement
4. Alternative: If FC inventory low, use next-nearest FC

## Pick & Pack
1. Mobile app alerts warehouse staff
2. Staff navigates to bin location (Kiva robots help)
3. Item picked from shelf
4. Scan barcode (verify correct item)
5. Carry to packing station
6. Pack with bubble wrap/padding
7. Seal and label

## Shipping Label & Carrier
1. Shipping label printed
2. Carrier selected (UPS, FedEx, USPS, Amazon Logistics)
3. Barcode scanned by carrier
4. Item on conveyor belt
5. Loaded to truck

## Delivery
1. Carrier delivery in transit
2. Real-time tracking (customer views)
3. Delivery attempt (1-3 attempts per Amazon policy)
4. Delivery confirmation
5. Photo at door (if requested)

## Post-Delivery
1. Tracking shows delivered
2. Customer reviews within 90 days
3. Return window: 30 days (most items)
4. Extended: 90 days for holiday purchases
5. Option: Return to Amazon hub or schedule pickup

## Return Processing
1. Initiate return (reason selection)
2. Generate return label (pre-paid)
3. Drop-off: Amazon Hub, Whole Foods, Kohl's, or pickup
4. Return received at warehouse
5. Inspection & refund initiated
6. Refund: T+2 to T+5 days

## Performance Metrics
- Order to delivery: 1-2 days (standard)
- Fulfillment time: <12 hours
- On-time delivery: 99.9%+
- Returns processing: <7 days refund
