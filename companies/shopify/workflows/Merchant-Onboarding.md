# Shopify: Merchant Onboarding Workflow

## Phase 1: Sign Up (5 minutes)
1. Email registration (or Google/Facebook login)
2. Store name (URL auto-generated)
3. Password creation
4. Account created (14-day free trial)
5. Welcome email sent

## Phase 2: Store Setup (15-30 minutes)
1. Theme selection (100+ free themes)
2. Customize theme (color, logo, fonts)
3. Add store information (address, phone, email)
4. Write store policies (privacy, returns, shipping)
5. Save and preview store

## Phase 3: Product Catalog (30-60 minutes)
1. Add first product (manual or import)
   - Product name
   - Photos (auto-optimize for web)
   - Description (suggestions provided)
   - Price (in store currency)
   - SKU (optional)
   - Inventory count

2. Add shipping method (flat rate, weight-based, or zones)
3. Set tax rates (auto-calculated for major jurisdictions)
4. Create collections (organize products)

## Phase 4: Payment Setup (10 minutes)
1. Select payment gateway (Stripe, PayPal, etc.)
2. Connect account (OAuth)
3. Enter payout information
4. Verify payment method
5. Shopify Payments option (2.9% + $0.30 fee)

## Phase 5: Domain (Optional)
1. Use free .myshopify.com domain
2. Or connect custom domain
3. SSL/TLS: Automatic (free)
4. DNS setup (if custom domain)

## Phase 6: Go Live (1 minute)
1. Unpublish password page (if had one)
2. Store now publicly accessible
3. Share store URL
4. Social media integration ready

## Phase 7: Post-Launch Support
1. Onboarding email sequence (10 emails)
2. Recommended apps (Payment, Shipping, Marketing)
3. Analytics dashboard (sales, traffic)
4. Staff access (multi-user support)
5. 24/7 support available

## Timeline
- Total: 1-2 hours from sign-up to live store
- Free trial: 14 days (no credit card initially)
- Trial conversion: 50%+ decide to keep store
- Upgrade: $29-299/month plans available

## Onboarding Success Metrics
- Sign-up completion: 80%+ complete onboarding
- First product: 90%+ add at least one product
- Go-live: 70%+ take store public
- Paid subscription: 50%+ convert after trial
