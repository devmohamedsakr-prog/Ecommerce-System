# Mercado Libre: Regional Seller Onboarding Workflow

## Brazil Workflow
1. Sign up (email, basic info)
2. CPF verification (Brazilian tax ID)
3. Bank account (local bank required)
4. Address verification (national registry)
5. Shop setup (name, policies)
6. First listing approved (quick review)
7. Payout setup (daily available)

Time: 24-48 hours

## Mexico Workflow
1. Sign up
2. RFC verification (tax ID)
3. OXXO cash payment setup (alternative to bank)
4. Address verification
5. Shop setup
6. First listing
7. Payout (weekly default)

Time: 3-5 days

## Colombia Workflow
1. Sign up
2. CC verification (national ID)
3. Bank account (local bank)
4. Address verification (telecom registry)
5. Shop setup
6. First listing (manual review, higher scrutiny)
7. Payout (T+2 days)

Time: 5-7 days (more conservative)

## Argentina Workflow
1. Sign up
2. CUIT verification (tax ID)
3. Bank account (if available, hard in Argentina)
4. Alternative: Cash payments accepted
5. Shop setup
6. First listing
7. Payout (Mercado Crédito account, deferred)

Time: 1-2 weeks

## Cross-Region Commonalities
- Email verification (immediate)
- ID verification (varies by country)
- Payout method setup (required)
- Shop basics (name, policies)
- First listing (auto or manual review)

## Support
- Local support team per country
- Language-specific help
- Payment method education
- Seller training program
