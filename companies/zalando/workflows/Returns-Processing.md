# Zalando: Returns Processing Workflow

## Return Initiation
1. Customer logs in
2. Select order to return
3. Select items to return (partial or full)
4. Reason (size, fit, color, damage, etc.)
5. Initiate return (creates RMA)

## Shipping Return
1. Prepaid label emailed (no cost to customer)
2. Package item (Zalando box optional)
3. Options: Ship or drop-off Zalando station
4. Tracking provided
5. Confirm shipment in app

## Warehouse Processing
1. Receive return
2. Quality check (any damage, tags attached)
3. Scan barcode (track in system)
4. Sort by condition
5. Bin to inventory or liquidation

## Inventory Disposition
- **Sellable:** Return to inventory (immediately)
- **Minor damage:** Discount section (10-30% off)
- **Significant damage:** Liquidation (auction houses)
- **Defective:** Vendor return (charge-back)

## Refund Processing
1. Inspection complete
2. Condition assessed
3. System triggers refund
4. Payment processor: Refund initiated
5. Customer receives: 5-10 days (bank dependent)

## Return Statistics
- Return rate: 30-50% (fashion industry normal)
- Most common reason: Size/fit (50%)
- Second: Color/look (20%)
- Actual defect: <5%

## Operational Scale
- Daily returns: 100K+ items
- Processing time: <48 hours
- Refund cycle: 5-10 days (including bank)
- Cost: $3-5 per return (amortized)

## Sustainability Benefit
- Restock: 70% of returns resold
- Reduction: Waste minimized
- Liquidation: Give items second life
- Result: Environmental responsibility positioning
